# 本场 C1 四条件正式对比

协议：`commanded = ours/source_va`（同一回复轨迹）；`detected = 各条件面部 VA`。
事件窗 2.0s，source EMA τ=0.6s，**统一固定滞后 0.5s**（四条件同一对齐，避免自由搜滞后让静止/乱序脸拟合噪声占便宜）。
方向命中为 **trial 级聚类** 统计：先算每条 trial 的命中率再对 trial 做 bootstrap（同一 trial 内的重叠窗口不是独立样本）。
指令裁剪到可渲染 [-1,1]（proto_anchor 将约 12% token 推出量程，饱和段按构造不可检验）。
Mirror 读数经**静止脸校准**：用 mishra/xpress 40 段已知显示 VA 的视频拟合线性校准（检测效价被压缩约 4x 且混入唤醒分量）；校准集与被测数据独立，四条件同一映射。

## 读法

- **方向命中 (V_dir_acc_thr0.3)**：指令轨迹大幅摆动时，脸上是否同向（机会水平 50%）；p 为 trial 聚类 bootstrap 单侧 p（>0.5）。
- **R² gain**：相对「整句一个表情」，token 级轨迹多解释多少脸上方差（对固定脸基线增益应接近 0）。
- Mishra/Xpress 为话轮级固定表情；random 为打乱时间结构；ours 为逐 token。
