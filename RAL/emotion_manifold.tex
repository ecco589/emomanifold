\begin{abstract}
面部是人机交互中最自然的情绪入口；随着面部硬件与大模型表征能力成熟，面部机器人已走向落地，但如何让表情随对话快速、灵动地响应并传递可识别的情绪信息，仍缺少可靠路径。
现有方案依赖 LLM 为每句话输出离散情感标签驱动面部，句级信号无法跟随句内变化，细腻情绪被抹平。
我们提出 EmotionManifold：不令模型``说出''情绪，而在流式解码中直接读回其内部连续表征，投影至 VAD 情感子空间并经 FKCN 映射至 29 自由度面部机器人，使表情与 token 生成同步更新，情感信号直接来自模型内部表征，而非外部情感标签。
三组客观实验分别验证情感子空间可读性（$\rho=0.837$）、同词跨语境效价对照（$\Delta V\approx-0.22$）及实机执行保真度，表明内部表征与面部执行的直接关联可支撑快速、细腻、可验证的交互式情感表达。
\end{abstract}

\section{INTRODUCTION}

在具身智能的发展蓝图中，尽管主流范式侧重于使机器人掌握操纵等实用物理技能，但大语言模型（LLM）强大的表征能力与高自由度面部硬件的同步成熟，正推动面向陪伴与交互的面部机器人（Facial Robots）成为率先落地的核心载体之一（Ahmed et al., 2024）。
为实现自然灵动的人机交互，在工程层面上，语言-表情同步（Speech-Expression Synchronization）是亟待突破的重要瓶颈。

``It's written all over your face.''神经科学研究表明，皮层下通路（Subcortical Pathways）可在人类有意识地进行语言表述之前驱动面部表情的变化，使情绪信号往往先于言语显现（LeDoux, 1996）。
面部机器人应当复现这一生理机制以达到更接近人类交互的效果：即情绪信号应直接从模型内部的认知表征中提取，并流式驱动表情更新。
然而，当前主流方案——无论是早期的显式规则切换，还是近期基于 LLM 的结构化输出与非言语行为调度——普遍令模型在生成对话内容的同时附带离散情绪标签，再据此映射预设表情；标签虽可与回复一并产生，其语义单元仍停在话轮（Turn）尺度。相比之下，语言生成是以 Token 为基本单元自回归流式推进的，其内部往往交织着高频的句内（Intra-utterance）情感转折。这种时序粒度错配（Temporal Granularity Mismatch）不可避免地导致了面部执行相对于语言内容轨迹的错位，并在整句尺度上粗暴地抹平了本应精细可辨的动态情感轨迹。

为了解决上述瓶颈，本文提出了 EmotionManifold：一种在流式解码过程中直接从大模型隐状态（Hidden States）中读回连续情感坐标，并实时外显为机器人面部微表情的全新架构。
在表征机制上，我们通过在解嵌入矩阵（Unembedding Matrix）上聚类情感词簇，构造三条 VAD 情感轴并张成三维情感子空间。在运行期，随着 Token 的逐个发射，瞬时隐状态被流式投影至该子空间，生成连续演进的情感轨迹 $\mathrm{VAD}(t)$；该轨迹随即通过模糊 Kohonen 聚类网络（FKCN）（Han et al., 2013）转换为七种基础表情的非线性融合权重，无缝映射至 29 自由度面部硬件系统。该方案具有天然的优雅与轻量性：它摒弃了独立的外部情感 API 与繁重的参数微调，仅依赖离线空间标定与原生前向传播即可在本地开源模型上高效运行。通过这种方式，面部物理执行与认知 Token 发射共享同一时钟，实现了“情动于内、形于外”的效果。

本文的主要贡献如下：
\begin{itemize}
\item \textbf{提出一条免训练、可实时运行的表情驱动管线：}在模型解嵌入矩阵上离线构造三条 VAD 情感轴并张成情感子空间，于流式解码过程中对隐状态做投影（词级读回精度 Spearman $\rho_V = 0.837$），再经 FKCN 与预置表情映射至高自由度面部执行器；无需参数微调或外部情感接口，附加计算仅为三次投影运算，便于本地部署。
\item \textbf{实现与语言生成同步的细粒度表情控制：}与以话轮为单位输出离散情绪标签的现有做法不同，本方法在每个生成 token 上更新连续情感坐标；同词跨语境对照表明，正面关键词在复杂情感（如讽刺）条件下的 token 级效价显著下降（$\Delta V \approx -0.22$），说明驱动信号能够反映句内语用转折，而非表面词汇查表。
\item \textbf{从表征到实机对上述管线进行客观验证：}在公开词典与讽刺压力测试上检验读回一致性与语境敏感性，并在 29 自由度实机上以四条件同场对照经视觉回读评估执行保真度（句内效价转折方向命中率 $87.5\%$，话轮级与乱序基线均在机会水平），为该方法提供可复现的定量证据。
\end{itemize}

\section{RELATED WORK}
\label{sec:related}

机器人面部表情生成的研究可追溯至基于面部运动编码系统（FACS）的动作单元（Action Unit）描述传统（Ekman \& Friesen, 1978），以及早期交互系统（如 Kismet）在二维情感空间（Affect Space）中实现连续动态表情过渡的开创性实践（Breazeal, 2003）。Rawal 与 Stock-Homburg（2022）的系统综述指出，数据集上的表情识别已相对成熟，但实时识别仍较弱，且机器人表情生成仍以手工编码为主、自动化管线不足。在此基础上，与流式言语（Unfolding Speech）高频同步的自适应表情控制，仍是 HRI 中的突出瓶颈。在实体执行层，高度仿真的面部硬件平台如 Emo（Hu et al., 2024）以及面向 Ameca 机器人的 X2C 数据集（Li et al., 2025），推动了高自由度机械面部的连续形变能力；在控制层，学术界与工业界已迅速转向大语言模型（LLM）驱动的范式——从 FurChat（Cherakara et al., 2023）、SAFE（Lee et al., 2023）、Nadine（Kang et al., 2024）到最新的 Expressive Furhat（Abbo et al., 2026）。其中，Mishra 等（2023）根据对话历史为即将发出的话轮预测离散情绪并映射面部动作；Xpress（Antony et al., 2025）则由语言模型输出情绪类别与强度，以生成与语境相关的表情。二者代表当前以外部离散标签驱动机器人面部的主流路线，也是本文实验的主要对照系统。
然而，语言生成以 token 为基本单元自回归推进，句内否定、转折与讽刺等变化要求表情控制具备同等时间分辨率；上述路线虽可将表情标签与回复一并产出（或由话轮语境另路推断），但其控制变量仍是附着于整句或话轮的离散符号，结构性上无法刻画 token 级连续漂移。连续情感坐标——尤其是效价—唤醒度—支配度（VAD）空间（Russell \& Mehrabian, 1977; Mohammad, 2018）——为细粒度表情驱动提供了比离散类别更合适的中间表示；机制可解释性亦表明，LLM 隐空间中存在可线性读出的情感结构，如效价方向（Tigges et al., 2024）及更一般的低维情感流形（Reichman et al., 2026）。据此，本文不再将表情编码为离散符号字段，而是从解码隐状态直接读回连续 VAD 轨迹，并以 token 时钟驱动面部执行，在内部表征与具身表情之间建立同频通道。

\section{METHOD}
\label{sec:method}

图~\ref{fig:architecture}概述了 EmotionManifold 的整体架构。
给定用户输入，LLM 以自回归方式流式生成回复；每发射一个 token，其末层隐状态即被投影到离线构造的 VAD 情感子空间中，得到连续情感轨迹 $\mathrm{VAD}(t)$；该轨迹由模糊 Kohonen 聚类网络（FKCN）转换为七种基本表情的融合权重，再经预置表情（preset）融合下发至 29 自由度面部硬件。
借鉴逆模型学习框架的问题分解思想（Chen et al., 2021; Hu et al., 2024），我们将``从语言内部表征到物理表情''这一端到端问题分解为三个可独立标定的阶段：（A）情感轴挖掘与子空间标定、（B）逐 token 流式投影、（C）表情映射与执行。
其中阶段 A 为一次性离线过程，B 与 C 在运行期以原生前向传播的开销实时完成，全程无需微调或外部情感 API。

\subsection{情感轴挖掘与子空间标定}
\label{sec:axis_mining}

本阶段的目标是在不引入任何训练的前提下，于 LLM 隐空间中显式构造出与心理学 VAD 模型（Russell \& Mehrabian, 1977）对齐的三条情感轴，并由其张成三维 VAD 情感子空间。
设 $\mathbf{W}_{\mathrm{out}} \in \mathbb{R}^{|\mathcal{V}| \times d}$ 为模型的解嵌入（unembedding）矩阵，其中 $|\mathcal{V}|$ 为词表大小、$d$ 为隐层维度。
参照隐空间线性表征假设及均值差方向提取方法（Tigges et al., 2024），我们从 NRC-VAD 词典（Mohammad, 2018）中为每一维度选取得分最高与最低的各 $N$ 个词，构成极词簇（pole word clusters）$\mathcal{C}^{+}_k$ 与 $\mathcal{C}^{-}_k$，$k \in \{V, A, D\}$。
对每个词簇计算其在解嵌入矩阵中的平均嵌入：
\begin{equation}
    \bar{\mathbf{e}}_{\mathcal{C}} = \frac{1}{|\mathcal{C}|}\sum_{w \in \mathcal{C}} \mathbf{W}_{\mathrm{out}}[\mathrm{id}(w)],
\end{equation}
其中 $\mathrm{id}(w)$ 为词 $w$ 首个内容 token 的索引。
第 $k$ 维情感轴定义为两簇质心的归一化差向量：
\begin{equation}
    \mathbf{v}_k = \frac{\bar{\mathbf{e}}_{\mathcal{C}^{+}_k} - \bar{\mathbf{e}}_{\mathcal{C}^{-}_k}}{\bigl\|\bar{\mathbf{e}}_{\mathcal{C}^{+}_k} - \bar{\mathbf{e}}_{\mathcal{C}^{-}_k}\bigr\|_2}.
    \label{eq:valence_axis}
\end{equation}
三条情感轴 $\{\mathbf{v}_V, \mathbf{v}_A, \mathbf{v}_D\}$ 共同张成 VAD 情感子空间；后文在讨论逐维投影与构轴过程时称``情感轴''，在讨论轨迹几何、正交性与表情映射时称``情感子空间''。
极词数 $N$ 在轴的稳定性与语义特异性之间权衡：$N$ 过小则轴易受个别词的特异性干扰，过大则混入弱情感词而稀释方向。
我们在实验部分对 $N \in [10, 80]$ 进行扫描（第 IV-A 节），并采用 $N = 50$ 作为默认配置。
由于原始投影值的数值范围依模型与维度而异，我们另以少量含词典词的句子做一次性离线最小二乘拟合，得到逐维仿射参数 $(s_k, b_k)$，将投影值对齐至词典语义尺度 $[-1, 1]$（AdaptiveScaler）；推理时该参数固定。
整个阶段是模型特定的——每个 backbone 需独立重算三条情感轴——但完全免训练：仅需词典筛选与对 $\mathbf{W}_{\mathrm{out}}$ 的一次只读访问，在消费级硬件上数秒内即可完成。

\subsection{逐 Token 流式投影}
\label{sec:projection}

运行期，模型以因果解码逐 token 生成回复。
在第 $t$ 步，设 $\mathbf{h}_t \in \mathbb{R}^{d}$ 为末层最后位置的隐状态，即刚发射 token 的上下文表示。
我们对其做 L2 归一化以消除隐状态范数随位置的漂移，再沿三条情感轴投影至 VAD 情感子空间并施加标定：
\begin{equation}
    \hat{\mathbf{h}}_t = \frac{\mathbf{h}_t}{\|\mathbf{h}_t\|_2}, \qquad
    \tilde{z}_{t,k} = \mathrm{clip}\bigl(s_k\, \mathbf{v}_k^\top\hat{\mathbf{h}}_t + b_k,\, -1,\, 1\bigr), \quad k \in \{V, A, D\}.
    \label{eq:projection}
\end{equation}
由此得到与 token 发射严格同步的连续情感轨迹 $\{\tilde{\mathbf{z}}_t\}$。
区别于将离散情感标签作为结构化输出字段、以话轮为语义单元的调度方案（Mishra et al., 2023），该读回在每个解码步即时可用，天然具备句内时间分辨率——这正是捕捉否定、转折与讽刺等句内情感漂移的结构性前提。
由于隐状态在标准前向传播中本已计算，投影仅引入三次 $d$ 维点积，实机工控机上的逐 token 附加开销实测 $0.7$ ms（第~\ref{sec:exp_hardware}节）；整条链路在本地 CPU 上即可维持实时。

面向两类下游用途，我们对轨迹做不同的后处理。
（1）离线评测：需要句级坐标时，采用末内容 token 聚合或长度加权平均；token 级分析（如讽刺触发词的跨语境对照）则直接保留关键词位置的 $\tilde{z}_{t,V}$。
（2）在线执行：对送入下游表情映射的信号流施加指数滑动平均（EMA，$\alpha = 0.6$）以抑制逐 token 抖动。
平滑仅作用于硬件显示通路，评测所用的原始读回不受影响。

\subsection{表情映射与执行}
\label{sec:actuator}

直接在 VAD 情感子空间中逐自由度标定机器人面部代价高昂且不可迁移；相比之下，基本表情空间为面部硬件提供了自然的标定基。
为此我们采用模糊 Kohonen 聚类网络（FKCN）（Han et al., 2013），将该子空间中的点连续映射为七种基本表情（中性、快乐、惊讶、恐惧、悲伤、厌恶、愤怒）的融合权重 $\boldsymbol{\omega}_t \in \Delta^{6}$（非负且和为一）。

FKCN 由 $P = 13$ 个模糊原型 $\{(\mathbf{c}_j, \mathbf{w}_j)\}_{j=1}^{P}$ 构成，其中 $\mathbf{c}_j \in \mathbb{R}^3$ 为原型在情感子空间中的坐标，$\mathbf{w}_j$ 为该原型所属基本表情的 one-hot 向量；原型坐标在环状情感模型（circumplex model）（Russell, 1980）所给出的效价--唤醒度区位基础上，进一步沿支配度维扩展锚定，使七种基本情绪在完整 VAD 情感子空间中各据典型区域。
给定输入 $\mathbf{p}_t = (\tilde{z}_{t,V}, \tilde{z}_{t,A}, \tilde{z}_{t,D})$，计算其到各原型的平方距离 $d_{tj} = \|\mathbf{p}_t - \mathbf{c}_j\|^2$，并由反距离归一化得到模糊隶属度
$\mu_{tj} = \bigl(d_{tj}\sum_{l=1}^{P} d_{tl}^{-1}\bigr)^{-1}$（与原型重合时退化为硬指派）。
输出权重为隶属度对原型标签的加权和：
\begin{equation}
    \boldsymbol{\omega}_t = \sum_{j=1}^{P} \mu_{tj}\, \mathbf{w}_j .
    \label{eq:fkcn}
\end{equation}
与最近邻式的硬分类不同，该映射在整个 VAD 情感子空间中连续：位于原型之间的坐标产生多种基本表情的软混合而非离散跳变，延续了 Kismet 以来``情感状态是连续空间中一个移动的点''的表达传统（Breazeal, 2003）。

执行层将七维权重融合为舵机指令。
每种基本表情对应一个离线标定的预置向量（preset）$\mathbf{p}^{(m)} \in [0,1]^{29}$：标定时逐关节调节物理面部至该表情的目标位形，并按各通道行程上下限将关节角归一化为无量纲因子（factor）。
运行期，29 维目标因子由 FKCN 权重对预置向量线性融合得到：
\begin{equation}
    \mathbf{f}_t = \sum_{m=1}^{7} \omega_{t,m}\, \mathbf{p}^{(m)}, \qquad \mathbf{f}_t \leftarrow \mathrm{clip}(\mathbf{f}_t,\, 0,\, 1),
    \label{eq:fusion}
\end{equation}
再经逐通道行程映射转换为舵机角度，通过串口下发。
为在离散 token 事件与固定节拍的硬件刷新之间桥接，我们以 10\,fps 对相邻表情目标做缓入缓出（smoothstep）插值，并施加单帧变化上限（每因子每帧至多 0.05），以匹配舵机物理响应极限并避免高频抖动；单次运动窗口与帧周期对齐（100\,ms）。

值得强调的是，上述融合在预置表情权重空间中进行，与具体舵机运动学解耦。
若更换面部显示方式，只需为新的显示端重新设定表情映射，从隐状态到 VAD 情感子空间、再到 FKCN 的计算不必改动。
实验部分用 Grimace 仿真脸展示这一迁移；在 29 自由度实体面部机器人上完成执行保真度等定量评估。
该设定与依赖平台特定逆模型学习的方案（Chen et al., 2021; Hu et al., 2024）不同。

\section{EXPERIMENTS}
\label{sec:experiments}

实验回答三个层层递进的问题：（A）由情感轴张成的 VAD 情感子空间，其逐维读回是否与人工标注一致、几何结构是否可靠？（B）在句子语境中，投影读出的情感是否反映说话人的真实意图，而不是简单复读表面词汇？（C）该情感信号经映射与执行后，能否在实机面部上保真呈现？除特别说明外，实验模型默认为Qwen2.5-0.5B，情感轴与标定参数按第~\ref{sec:axis_mining}节所述、以每极 50 个英文极词离线构建；所有评测只做前向传播，不涉及任何参数更新。

\subsection{情感子空间可靠性}
\label{sec:exp_subspace}

如果一条情感轴是可靠的，那么把任意情感词的嵌入向量投影到这条轴上，得到的分值排序应当与人工标注的效价排序一致。具体地，从 NRC-VAD 词典（Mohammad, 2018）中另取 300 个未参与构轴筛选的评测词（每个维度 100 词，按该词在 NRC 标注中最突出的维度归组），将每个词在解嵌入矩阵中的行向量归一化后与对应轴做点积、经仿射标定，得到模型分值，再与 NRC 人工分值计算 Spearman 秩相关 $\rho$。为了让不同模型在完全相同的词表上评测、结果可直接比较，评测词均筛选为在全部五个对照模型（2B--8B 的五个开源 LLM）的分词器中都恰好编码为单个 token 的词——多 token 词在解嵌入矩阵中没有唯一的行向量，无法跨模型公平对比。

轴的质量取决于每极选多少个极词（$N$）。图~\ref{fig:e1_pole_sweep}展示了 $N$ 从 10 到 80 变化时，六个模型（五个对照模型加本文部署的 Qwen2.5-0.5B）在同一评测词表上的 $\rho$。三个维度呈现一致的规律：$N$ 较小时轴不稳定，随 $N$ 增大相关性上升，并在 $N \approx 50$ 后饱和——六模型均值上，效价 $\rho_V$ 从 0.73 升至 0.79，唤醒度 $\rho_A$ 从 0.51 升至 0.75，支配度 $\rho_D$ 从 0.49 升至约 0.65。据此全文取 $N{=}50$。值得注意的是，参数量仅为对照模型 1/4 至 1/16 的 Qwen2.5-0.5B 并未掉队：$N{=}50$ 时其 $\rho_V = 0.837$（$p < 10^{-26}$，$n{=}100$）位于六模型区间的上沿，$\rho_A = 0.665$、$\rho_D = 0.663$ 落在区间内偏下。改用中文极词重复整个流程（中文评测词表按同样的单 token 原则另建），得到 $\rho_V = 0.823$、$\rho_A = 0.803$、$\rho_D = 0.702$，说明该构造对构轴语言不敏感。

\subsection{语境敏感性：讽刺压力测试}
\label{sec:exp_sarcasm}

词级相关只证明了投影与词典先验一致；如果读回本质上等价于查词典，它对 ``lovely'' 永远输出正效价，也就无法驱动跟随句内语用转折的表情。讽刺恰好是检验这一点的对抗场景：讽刺句用正面措辞传递负面意图，表面词汇与真实情感方向相反（Abu Farha et al., 2022）。

我们以 iSarcasmEval SubTask C 英文测试集为底本，它提供 200 对``讽刺句 + 表达相同意图的非讽刺改写''。直接使用原句有两个问题：许多句子依赖特定文化背景（球队、政客、品牌），且孤立引语不含判断讽刺所需的情境。因此我们按固定协议将每对人工改写为一组语境三元组，每条由``一句可观察的情境 + 一句引语''构成，三个条件共享同一说话人意图：S（讽刺）在不利情境下给出正面引语，如\emph{朋友抱怨球队昨晚又输了，我说：``你们队今天打得真好！''}；P（真诚正面）在有利情境下给出同一句正面引语，如\emph{朋友庆祝球队昨晚赢了，我说：``你们队今天打得真好！''}；N（字面负面）在不利情境下给出负面引语，如\emph{朋友抱怨球队又输了，我说：``很遗憾你们队没赢。''}。关键设计在于 S 与 P 的引语逐词相同，仅一句情境不同——任何两条件间的投影差异只能来自语境。改写时以通用日常场景替换文化专名，并为每条标注 1--3 个锚定情绪关键词（如上例中的 well）。全部 200 组三元组连同改写协议随论文发布。

三元组经与全文相同的前向管线投影。句级效价取句末 token 的标定投影值（因果注意力下，末 token 的隐状态汇聚了整句信息）；关键词级取锚定关键词所在 token 位置的投影值。可证伪的预测是：若读回由表面词汇决定，则措辞相同的 S 与 P 应得到同样的高效价；若读回整合了语境，则 S 应向意图相同的 N 靠拢。

作为参照，在不加情境的原始句上（10 对开发样本），讽刺句的投影效价保持强正（$\bar{V}_S \approx 0.42$），比其字面负面改写高出约 0.41——不出所料，孤立句子中模型只能看到正面词汇。而在注入一句情境后的全部 200 组上，格局明显改变：$\bar{V}_S = 0.46$、$\bar{V}_P = 0.65$、$\bar{V}_N = 0.40$。讽刺句与字面负面句的效价差收窄至 $+0.06$，81.5\% 的三元组中两者相差不足 0.15，即讽刺句在句级上已与``负面意图''基本重合；同时，引语完全相同的 S 显著低于 P（差 $-0.19$）。三组配对差异均通过 Wilcoxon 符号秩检验（$n{=}200$，均 $p < 10^{-11}$）。图~\ref{fig:b1_sarcasm_raincloud}给出三条件的完整分布及逐三元组的配对连线。

句级差异原则上仍可能由句中其他词贡献。为彻底排除词汇因素，我们把对比压缩到单个 token：同一个正面关键词（如 well），在 S 与 P 两句中位置与词形完全相同，仅前置情境不同。在每组的首要关键词上（$n{=}200$），讽刺语境下该词的投影效价系统性地低于真诚语境，平均差 $-0.22$；将统计范围扩大到所有在 S、P 中均出现的关键词（$n{=}325$），效应保持在 $-0.20$。相比之下，同一对照下唤醒度与支配度的偏移都小于 0.07——语境调制集中出现在效价维上，与讽刺``极性反转、而非唤醒改变''的语用学刻画一致（Leggitt \& Gibbs, 2000）。由于两句在该词上没有任何词形差异，这一结果无法用词典查表解释：隐状态在该 token 处携带的，是经过上下文整合后的情感表征。

综合两级证据：给定最少一句情境，句级效价即与说话人意图对齐；控制词形后，token 级效价仍随语境改变方向。这说明送往下游表情管线的信号反映的是语用层面的情感，为第~\ref{sec:exp_hardware}节的实机评估提供了上游依据。

\subsection{实机执行保真度}
\label{sec:exp_hardware}

前两节证明了上游信号的可靠性；本节回答链路的最后一问：逐 token 的情感指令经映射与舵机执行后，能否在物理面部上留下\emph{可回读}的痕迹——以及这一能力是否为逐 token 控制所独有。评测在同一机器人、同一机位的一场录制中比较四个条件：20 条覆盖基本情绪、EmoBank 效价/唤醒极值、GoEmotions 及句内转折类别的英文刺激句，逐条送入部署于机器人的 Qwen2.5-0.5B 流式管线现场生成回复；对\emph{同一段回复}，本文管线逐 token 驱动面部（ours），Mishra 式与 Xpress 式基线用 GPT-4o-mini 对回复文本做话轮级分类后整句定脸，随机对照将 ours 的 token 级轨迹打乱时间顺序后驱动。固定机位相机录制全程，离线用面部表情 VA 回读器逐帧估计面部效价与唤醒，与逐 token 指令轨迹（EMA $\tau{=}0.6$ s 平滑）对齐比较。

逐帧数值重合不是合理的判据——舵机带宽与回读器精度都有限；论文主张的是\emph{句内转折被朝正确方向执行}。因此以事件级二选一（2AFC）检验：当指令 VA 在 2 s 窗内摆动超过阈值（$|\Delta V|>0.3$、$|\Delta A|>0.2$）时，检查面部回读同窗变化的符号是否一致（机会水平 50\%）。由于同一录音内的滑窗高度重叠，统计一律先聚合为逐条录音的命中率、再对录音做 bootstrap。另以方差分解量化 token 级轨迹相对``整句一个表情''话轮级基线的 $R^2$ 增益；话轮级基线的面部恒定，该指标按构造为零，天然构成阴性对照。

结果（图~\ref{fig:c1_main}）：只有 ours 的面部在句内跟随指令。效价大摆动方向命中 87.5\%（123 个事件/18 条含事件录音，95\% CI $[76.7, 96.0]$，$p<10^{-4}$），唤醒 69.6\%（CI $[56.8, 81.7]$，$p{=}0.001$）；token 级轨迹相对话轮级基线额外解释 21.8\%（效价）与 18.9\%（唤醒）的面部方差；逐条录音的循环移位替代数据检验中，效价 16/20、唤醒 11/20 条显著（Fisher 合并 $p<10^{-23}$）。三条基线在两个维度上均不高于机会水平（效价 37.2\%--46.5\%、唤醒 53.8\%--58.8\%，均不显著），$R^2$ 增益不超过 $+0.05$。

为排除对照不公：四条件共用同一固定 0.5 s 执行加检测滞后（逐条自由搜滞后会让静止/乱序脸拟合噪声占便宜）；面部回读经独立校准——用 40 段已知显示 VA 的静止脸录像拟合线性校准，修正回读器对风格化机器人脸约 5 倍的效价压缩与唤醒串扰，校准集与被测的动态数据完全独立、四条件共用同一映射。
