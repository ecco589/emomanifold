\begin{abstract}
面部是人机交互中最自然的情绪入口；随着面部硬件与大模型表征能力成熟，面部机器人已走向落地，但如何让表情随对话快速、灵动地响应并传递可识别的情绪信息，仍缺少可靠路径。
现有方案依赖 LLM 为每句话输出离散情感标签驱动面部，句级信号无法跟随句内变化，细腻情绪被抹平。
我们提出 EmotionManifold：不令模型``说出''情绪，而在流式解码中直接读回其内部连续情感空间，投影至 VAD 轴并经 FKCN 映射至 29 自由度面部机器人，使表情与 token 生成同步、信号更为 genuine。
三组客观实验分别验证情绪子空间可读性（$\rho=0.837$）、同词跨语境效价对照（$\Delta V\approx-0.22$）及实机执行保真度，表明内部表征与面部执行的直接关联可支撑快速、细腻、可验证的交互式情感表达。
\end{abstract}

\section{INTRODUCTION}

在具身智能的发展蓝图中，尽管主流范式侧重于使机器人掌握操纵等实用物理技能，但大语言模型（LLM）强大的表征能力与高自由度面部硬件的同步成熟，正推动面向陪伴与交互的面部机器人（Facial Robots）成为率先落地的核心载体之一（Ahmed et al., 2024）。
为实现自然灵动的人机交互，在工程层面上，语言-表情同步（Speech-Expression Synchronization）是亟待突破的重要瓶颈。

``It's written all over your face.''神经科学研究表明，皮层下通路（Subcortical Pathways）可在人类有意识地进行语言表述之前驱动面部表情的变化，使情绪信号往往先于言语显现（LeDoux, 1996）。
面部机器人应当复现这一生理机制以达到更接近人类交互的效果：即情绪信号应直接从模型内部的认知表征中提取，并流式驱动表情更新。
然而，当前主流方案——无论是早期的显式规则切换，还是近期基于 LLM 的话轮级情感推断与非言语行为调度——普遍依赖离散情绪标签来映射预设表情，且在时序上仅能按话轮（Turn）为单位进行更新。相比之下，语言生成是以 Token 为基本单元自回归流式推进的，其内部往往交织着高频的句内（Intra-utterance）情感转折。这种时序粒度错配（Temporal Granularity Mismatch）不可避免地导致了面部执行相对于语言的严重迟滞，并在整句尺度上粗暴地抹平了本应精细可辨的动态情感轨迹。

为了解决上述瓶颈，本文提出了 EmotionManifold：一种在流式解码过程中直接从大模型隐状态（Hidden States）中读回连续情感坐标，并实时外显为机器人面部微表情的全新架构。
在表征机制上，我们通过在解嵌入矩阵（Unembedding Matrix）上聚类情感词簇，在 LLM 隐空间内显式规整出正交的 V/A/D 几何流形。在运行期，随着 Token 的逐个发射，瞬时隐状态被流式投影至该流形，生成连续演进的情感轨迹 $\mathrm{VAD}(t)$；该轨迹随即通过模糊 Kohonen 聚类网络（FKCN）（Han et al., 2013）转换为七种基础表情的非线性融合权重，无缝映射至 29 自由度面部硬件系统。该方案具有天然的优雅与轻量性：它摒弃了独立的外部情感 API 与繁重的参数微调，仅依赖离线空间标定与原生前向传播即可在本地开源模型上高效运行。通过这种方式，面部物理执行与认知 Token 发射共享同一时钟，实现了“情动于内、形于外”的效果。

本文的核心贡献主要体现在以下三个方面：
\begin{itemize}
\item 提出免训练、可跨模型的 token 级连续情感读回机制：利用解嵌入矩阵的情感词簇构建 VAD 轴，在 LLM 流式解码过程中对隐状态进行连续投影，并与 FKCN（Han et al., 2013）及 preset 融合执行栈耦合，实现 token 级 VAD 流至高自由度面部的端到端驱动。
\item 进行了递进式的全栈客观验证：严谨评估了情感子空间的可靠性（Spearman $\rho = 0.837$）、同词跨语境下的效价敏感度（$\Delta V \approx -0.22$），并在 EmoBank 等公开基准数据集上验证了句级情感流的精准对齐。
\item 在 29 自由度实机上实现了闭环镜像测试：引入摄像头视觉回读闭环控制链路，定量检验并确证了底层硬件表达与上层大模型情感指令之间的高保真映射关系。
\end{itemize}

\section{RELATED WORK}
\label{sec:related}

机器人面部表情生成的研究可追溯至基于面部运动编码系统（FACS）的动作单元（Action Unit）描述传统（Ekman \& Friesen, 1978），以及早期交互系统（如 Kismet）在二维情感空间（Affect Space）中实现连续动态表情过渡的开创性实践（Breazeal, 2003）。Rawal 与 Stock-Homburg（2022）的系统综述指出，尽管情感识别技术的演进已相对成熟，但在人机交互（HRI）领域中，能够与流式言语（Unfolding Speech）在时序上高频同步并自适应生成的机器人表情控制架构，依然是亟待突破的薄弱环节。在实体执行层，高度仿真的面部硬件平台如 Emo（Hu et al., 2024）以及面向 Ameca 机器人的 X2C 数据集（Li et al., 2025），代表了高自由度机械面部在连续非线性形变控制上的最新进展；在控制层，学术界与工业界已迅速转向大语言模型（LLM）驱动的范式——从 FurChat（Cherakara et al., 2023）、SAFE（Lee et al., 2023）、Nadine（Kang et al., 2024）到最新的 Expressive Furhat（Abbo et al., 2026），LLM 已被广泛用于话轮级（Turn-level）的情感显式推断与非言语行为调度（Mishra et al., 2023）。
与之平行，心理学与情感计算领域通常采用效价—唤醒度—支配度（VAD）等低维连续空间来刻画人类情绪（Russell, 1980; Mohammad, 2018），EmoBank（Buechel \& Hahn, 2017）等语料库亦将句级 VAD 表征确立为可复现的对齐评估基准；而近期机制可解释性研究表明，Transformer 隐空间中存在与上述情感维度对齐、可线性探测的流形结构（Hollinsworth et al., 2024; Reichman et al., 2026），这一脉络意味着：VAD模型不仅是外部标注与心理学理论中的描述语言，更是已内嵌于 LLM 内部表征中的几何结构。进一步地，在单句内部，否定、转折及讽刺等深层语用动力学（Pragmatic Dynamics）常引发情感表征的高频非平稳漂移。iSarcasmEval 基准（Abu Farha et al., 2022）通过构建语意相近的讽刺“最小对”（Minimal Pairs），定量检验了这种瞬态表征扰动。尽管现有的表征调控路径——如激活转向（Activation Steering）（Turner et al., 2023; Dong et al., 2025）与指令微调（Zhang et al., 2024）——展现出较强的语义干预能力，但其作用边界仅止于文本符号的宏观统计风格。
不同于诉诸宏观符号标签的传统外源驱动方案，本框架旨在使物理面部的动态形变与神经网络的 Token 生成保持严格同频，在内部认知表征与外部具身执行之间建立直连通道。

\section{METHOD}
\label{sec:method}

图~\ref{fig:architecture}概述了 EmotionManifold 的整体架构。
给定用户输入，LLM 以自回归方式流式生成回复；每发射一个 token，其末层隐状态即被投影到离线挖掘的 VAD 情感轴上，得到连续情感轨迹 $\mathrm{VAD}(t)$；该轨迹由模糊 Kohonen 聚类网络（FKCN）转换为七种基本表情的融合权重，再经预置表情（preset）融合下发至 29 自由度面部硬件。
借鉴逆模型学习框架的问题分解思想（Chen et al., 2021; Hu et al., 2024），我们将``从语言内部表征到物理表情''这一端到端问题分解为三个可独立标定的阶段：（A）情感轴挖掘与标定、（B）逐 token 流式投影、（C）表情映射与执行。
其中阶段 A 为一次性离线过程，B 与 C 在运行期以原生前向传播的开销实时完成，全程无需微调或外部情感 API。

\subsection{情感轴挖掘与标定}
\label{sec:axis_mining}

本阶段的目标是在不引入任何训练的前提下，于 LLM 隐空间中显式构造出与心理学 VAD 模型（Russell \& Mehrabian, 1977）对齐的三条情感轴。
设 $\mathbf{W}_{\mathrm{out}} \in \mathbb{R}^{|\mathcal{V}| \times d}$ 为模型的解嵌入（unembedding）矩阵，其中 $|\mathcal{V}|$ 为词表大小、$d$ 为隐层维度。
参照隐空间线性表征假设及均值差方向提取方法（Tigges et al., 2024），我们从 NRC-VAD 词典（Mohammad, 2018）中为每一维度选取得分最高与最低的各 $N$ 个词，构成极词簇（pole word clusters）$\mathcal{C}^{+}_k$ 与 $\mathcal{C}^{-}_k$，$k \in \{V, A, D\}$。
对每个词簇计算其在解嵌入矩阵中的平均嵌入：
\begin{equation}
    \bar{\mathbf{e}}_{\mathcal{C}} = \frac{1}{|\mathcal{C}|}\sum_{w \in \mathcal{C}} \mathbf{W}_{\mathrm{out}}[\mathrm{id}(w)],
\end{equation}
其中 $\mathrm{id}(w)$ 为词 $w$ 首个内容 token 的索引。
第 $k$ 维情感轴定义为两簇质心的归一化差向量：
\begin{equation}
    \mathbf{v}_k = \frac{\bar{\mathbf{e}}_{\mathcal{C}^{+}_k} - \bar{\mathbf{e}}_{\mathcal{C}^{-}_k}}{\bigl\|\bar{\mathbf{e}}_{\mathcal{C}^{+}_k} - \bar{\mathbf{e}}_{\mathcal{C}^{-}_k}\bigr\|_2}.
    \label{eq:valence_axis}
\end{equation}
极词数 $N$ 在轴的稳定性与语义特异性之间权衡：$N$ 过小则轴易受个别词的特异性干扰，过大则混入弱情感词而稀释方向。
我们在实验部分对 $N \in [10, 80]$ 进行扫描（第 IV-A 节），并采用 $N = 50$ 作为默认配置。
由于原始投影值的数值范围依模型与维度而异，我们另以少量含词典词的句子做一次性离线最小二乘拟合，得到逐维仿射参数 $(s_k, b_k)$，将投影值对齐至词典语义尺度 $[-1, 1]$（AdaptiveScaler）；推理时该参数固定。
整个阶段是模型特定的——每个 backbone 需独立重算三条轴——但完全免训练：仅需词典筛选与对 $\mathbf{W}_{\mathrm{out}}$ 的一次只读访问，在消费级硬件上数秒内即可完成。

\subsection{逐 Token 流式投影}
\label{sec:projection}

运行期，模型以因果解码逐 token 生成回复。
在第 $t$ 步，设 $\mathbf{h}_t \in \mathbb{R}^{d}$ 为末层最后位置的隐状态，即刚发射 token 的上下文表示。
我们对其做 L2 归一化以消除隐状态范数随位置的漂移，再投影至三条情感轴并施加标定：
\begin{equation}
    \hat{\mathbf{h}}_t = \frac{\mathbf{h}_t}{\|\mathbf{h}_t\|_2}, \qquad
    \tilde{z}_{t,k} = \mathrm{clip}\bigl(s_k\, \mathbf{v}_k^\top\hat{\mathbf{h}}_t + b_k,\, -1,\, 1\bigr), \quad k \in \{V, A, D\}.
    \label{eq:projection}
\end{equation}
由此得到与 token 发射严格同步的连续情感轨迹 $\{\tilde{\mathbf{z}}_t\}$。
区别于话轮级方案在整句结束后才产生单一情感标签（Mishra et al., 2023），该读回在每个解码步即时可用，天然具备句内时间分辨率——这正是捕捉否定、转折与讽刺等句内情感漂移的结构性前提。
由于隐状态在标准前向传播中本已计算，投影仅引入三次 $d$ 维点积，附加延迟可忽略；整条链路在本地 CPU 上即可维持实时。

面向两类下游用途，我们对轨迹做不同的后处理。
（1）离线评测：与句级标注（如 EmoBank reader VAD）对比时，采用末内容 token 聚合或长度加权平均得到句级坐标；token 级分析（如讽刺触发词的跨语境对照）则直接保留关键词位置的 $\tilde{z}_{t,V}$。
（2）在线执行：对送入下游表情映射的信号流施加指数滑动平均（EMA，$\alpha = 0.6$）以抑制逐 token 抖动。
平滑仅作用于硬件显示通路，评测所用的原始读回不受影响。

\subsection{表情映射与执行}
\label{sec:actuator}

直接在 VAD 空间逐自由度标定机器人面部代价高昂且不可迁移；相比之下，基本表情空间为面部硬件提供了自然的标定基。
为此我们采用模糊 Kohonen 聚类网络（FKCN）（Han et al., 2013），将 VAD 三维空间中的点连续映射为七种基本表情（中性、快乐、惊讶、恐惧、悲伤、厌恶、愤怒）的融合权重 $\boldsymbol{\omega}_t \in \Delta^{6}$（非负且和为一）。

FKCN 由 $P = 13$ 个模糊原型 $\{(\mathbf{c}_j, \mathbf{w}_j)\}_{j=1}^{P}$ 构成，其中 $\mathbf{c}_j \in \mathbb{R}^3$ 为原型在 $(V, A, D)$ 空间中的坐标，$\mathbf{w}_j$ 为该原型所属基本表情的 one-hot 向量；原型坐标在环状情感模型（circumplex model）（Russell, 1980）所给出的效价--唤醒度区位基础上，进一步沿支配度维扩展锚定，使七种基本情绪在完整 VAD 空间中各据典型区域。
给定输入 $\mathbf{p}_t = (\tilde{z}_{t,V}, \tilde{z}_{t,A}, \tilde{z}_{t,D})$，计算其到各原型的平方距离 $d_{tj} = \|\mathbf{p}_t - \mathbf{c}_j\|^2$，并由反距离归一化得到模糊隶属度
$\mu_{tj} = \bigl(d_{tj}\sum_{l=1}^{P} d_{tl}^{-1}\bigr)^{-1}$（与原型重合时退化为硬指派）。
输出权重为隶属度对原型标签的加权和：
\begin{equation}
    \boldsymbol{\omega}_t = \sum_{j=1}^{P} \mu_{tj}\, \mathbf{w}_j .
    \label{eq:fkcn}
\end{equation}
与最近邻式的硬分类不同，该映射在整个 VAD 情感空间中连续：位于原型之间的坐标产生多种基本表情的软混合而非离散跳变，延续了 Kismet 以来``情感状态是连续空间中一个移动的点''的表达传统（Breazeal, 2003）。

执行层将七维权重融合为舵机指令。
每种基本表情对应一个离线标定的预置向量（preset）$\mathbf{p}^{(m)} \in [0,1]^{29}$：标定时逐关节调节物理面部至该表情的目标位形，并按各通道行程上下限将关节角归一化为无量纲因子（factor）。
运行期，29 维目标因子由 FKCN 权重对预置向量线性融合得到：
\begin{equation}
    \mathbf{f}_t = \sum_{m=1}^{7} \omega_{t,m}\, \mathbf{p}^{(m)}, \qquad \mathbf{f}_t \leftarrow \mathrm{clip}(\mathbf{f}_t,\, 0,\, 1),
    \label{eq:fusion}
\end{equation}
再经逐通道行程映射转换为舵机角度，通过串口下发。
为在离散 token 事件与固定节拍的硬件刷新之间桥接，我们以 10\,fps 对相邻表情目标做缓入缓出（smoothstep）插值，并施加单帧变化上限（每因子每帧至多 0.05），以匹配舵机物理响应极限并避免高频抖动；单次运动窗口与帧周期对齐（100\,ms）。

值得强调的是，上述融合完全在预置因子空间中进行，与具体硬件的运动学解耦：迁移至另一面部机器人平台仅需重新录制七个表情预置与一份关节行程配置，上游的``隐状态$\rightarrow$VAD$\rightarrow$FKCN''信号链无需任何改动。
这使得本方法区别于依赖平台特定逆模型学习的方案（Chen et al., 2021; Hu et al., 2024），以极低的标定成本实现跨平台部署。

\section{EXPERIMENTS}
\label{sec:experiments}

实验回答三个层层递进的问题：（A）从模型权重中挖掘出的 VAD 轴，给出的分值是否与人工标注一致、其几何结构是否可靠？（B）在句子语境中，投影读出的情感是否反映说话人的真实意图，而不是简单复读表面词汇？（C）该情感信号经映射与执行后，能否在实机面部上保真呈现？除特别说明外，实验模型默认为Qwen2.5-0.5B，情感轴与标定参数按第~\ref{sec:axis_mining}节所述、以每极 50 个英文极词离线构建；所有评测只做前向传播，不涉及任何参数更新。

\subsection{情感子空间可靠性}
\label{sec:exp_subspace}

如果一条效价轴是可靠的，那么把任意情感词的嵌入向量投影到这条轴上，得到的分值排序应当与人工标注的效价排序一致。具体地，从 NRC-VAD 词典（Mohammad, 2018）中另取 300 个未参与构轴筛选的评测词（每个维度 100 词，按该词在 NRC 标注中最突出的维度归组），将每个词在解嵌入矩阵中的行向量归一化后与对应轴做点积、经仿射标定，得到模型分值，再与 NRC 人工分值计算 Spearman 秩相关 $\rho$。为了让不同模型在完全相同的词表上评测、结果可直接比较，评测词均筛选为在全部五个对照模型（2B--8B 的五个开源 LLM）的分词器中都恰好编码为单个 token 的词——多 token 词在解嵌入矩阵中没有唯一的行向量，无法跨模型公平对比。

轴的质量取决于每极选多少个极词（$N$）。图~\ref{fig:e1_pole_sweep}展示了 $N$ 从 10 到 80 变化时，六个模型（五个对照模型加本文部署的 Qwen2.5-0.5B）在同一评测词表上的 $\rho$。三个维度呈现一致的规律：$N$ 较小时轴不稳定，随 $N$ 增大相关性上升，并在 $N \approx 50$ 后饱和——六模型均值上，效价 $\rho_V$ 从 0.73 升至 0.79，唤醒度 $\rho_A$ 从 0.51 升至 0.75，支配度 $\rho_D$ 从 0.49 升至约 0.65。据此全文取 $N{=}50$。值得注意的是，参数量仅为对照模型 1/4 至 1/16 的 Qwen2.5-0.5B 并未掉队：$N{=}50$ 时其 $\rho_V = 0.837$（$p < 10^{-26}$，$n{=}100$）位于六模型区间的上沿，$\rho_A = 0.665$、$\rho_D = 0.663$ 落在区间内偏下。改用中文极词重复整个流程（中文评测词表按同样的单 token 原则另建），得到 $\rho_V = 0.823$、$\rho_A = 0.803$、$\rho_D = 0.702$，说明该构造对构轴语言不敏感。

\subsection{语境敏感性：讽刺压力测试}
\label{sec:exp_sarcasm}

词级相关只证明了投影与词典先验一致；如果读回本质上等价于查词典，它对 ``lovely'' 永远输出正效价，也就无法驱动跟随句内语用转折的表情。讽刺恰好是检验这一点的对抗场景：讽刺句用正面措辞传递负面意图，表面词汇与真实情感方向相反（Abu Farha et al., 2022）。

我们以 iSarcasmEval SubTask C 英文测试集为底本，它提供 200 对``讽刺句 + 表达相同意图的非讽刺改写''。直接使用原句有两个问题：许多句子依赖特定文化背景（球队、政客、品牌），且孤立引语不含判断讽刺所需的情境。因此我们按固定协议将每对人工改写为一组语境三元组，每条由``一句可观察的情境 + 一句引语''构成，三个条件共享同一说话人意图：S（讽刺）在不利情境下给出正面引语，如\emph{朋友抱怨球队昨晚又输了，我说：``你们队今天打得真好！''}；P（真诚正面）在有利情境下给出同一句正面引语，如\emph{朋友庆祝球队昨晚赢了，我说：``你们队今天打得真好！''}；N（字面负面）在不利情境下给出负面引语，如\emph{朋友抱怨球队又输了，我说：``很遗憾你们队没赢。''}。关键设计在于 S 与 P 的引语逐词相同，仅一句情境不同——任何两条件间的投影差异只能来自语境。改写时以通用日常场景替换文化专名，并为每条标注 1--3 个锚定情绪关键词（如上例中的 well）。全部 200 组三元组连同改写协议随论文发布。

三元组经与全文相同的前向管线投影。句级效价取句末 token 的标定投影值（因果注意力下，末 token 的隐状态汇聚了整句信息）；关键词级取锚定关键词所在 token 位置的投影值。可证伪的预测是：若读回由表面词汇决定，则措辞相同的 S 与 P 应得到同样的高效价；若读回整合了语境，则 S 应向意图相同的 N 靠拢。

作为参照，在不加情境的原始句上（10 对开发样本），讽刺句的投影效价保持强正（$\bar{V}_S \approx 0.42$），比其字面负面改写高出约 0.41——不出所料，孤立句子中模型只能看到正面词汇。而在注入一句情境后的全部 200 组上，格局明显改变：$\bar{V}_S = 0.46$、$\bar{V}_P = 0.65$、$\bar{V}_N = 0.40$。讽刺句与字面负面句的效价差收窄至 $+0.06$，81.5\% 的三元组中两者相差不足 0.15，即讽刺句在句级上已与``负面意图''基本重合；同时，引语完全相同的 S 显著低于 P（差 $-0.19$）。三组配对差异均通过 Wilcoxon 符号秩检验（$n{=}200$，均 $p < 10^{-11}$）。图~\ref{fig:b1_sarcasm_raincloud}给出三条件的完整分布及逐三元组的配对连线。

句级差异原则上仍可能由句中其他词贡献。为彻底排除词汇因素，我们把对比压缩到单个 token：同一个正面关键词（如 well），在 S 与 P 两句中位置与词形完全相同，仅前置情境不同。在每组的首要关键词上（$n{=}200$），讽刺语境下该词的投影效价系统性地低于真诚语境，平均差 $-0.22$；将统计范围扩大到所有在 S、P 中均出现的关键词（$n{=}325$），效应保持在 $-0.20$。相比之下，同一对照下唤醒度与支配度的偏移都小于 0.07——语境调制集中出现在效价维上，与讽刺``极性反转、而非唤醒改变''的语用学刻画一致（Leggitt \& Gibbs, 2000）。由于两句在该词上没有任何词形差异，这一结果无法用词典查表解释：隐状态在该 token 处携带的，是经过上下文整合后的情感表征。

综合两级证据：给定最少一句情境，句级效价即与说话人意图对齐；控制词形后，token 级效价仍随语境改变方向。这说明送往下游表情管线的信号反映的是语用层面的情感，为第~\ref{sec:exp_hardware}节的实机评估提供了上游依据。
