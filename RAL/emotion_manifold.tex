\begin{abstract}
面部作为人机交互中最自然的情绪入口，其交互潜能正随着高自由度面部硬件与大语言模型表征能力的成熟而被加速释放。然而，要实现表情随对话快速、灵动响应并准确传递情绪信息，目前仍缺乏可靠的技术路径。现有大模型驱动方案普遍依赖句级离散情感标签，导致表情更新滞后且无法表达句内细腻的情绪转折。为此，我们提出 EmoManifold：不令模型``说出''情绪，而是在流式解码中直接从模型隐状态提取连续情感表征并实时驱动面部硬件，实现了表情与 Token 生成的同步。实验表明，相比传统的话轮级控制基线，该方法不仅在复杂语境下展现出词级情感捕捉能力（同词跨语境效价差 $\Delta V\approx-0.22$），将表情响应延迟降低了一个数量级，更在实机面部执行时提升了对句内动态情绪转折的拟合精度（效价与唤醒度的 $R^2$ 分别提升 22 与 19 个百分点），指向快速、细腻且可验证的具身情感交互。
\end{abstract}

\section{INTRODUCTION}

在具身智能的发展蓝图中，尽管主流范式侧重于使机器人掌握操纵等实用物理技能，但大语言模型（LLM）强大的表征能力与高自由度面部硬件的同步成熟，正推动面向陪伴与交互的面部机器人（Facial Robots）成为率先落地的核心载体之一~\cite{ahmed2024companionship}。为实现自然灵动的人机交互，在工程层面上，语言-表情同步（Speech-Expression Synchronization）是亟待突破的重要瓶颈。

``It's written all over your face.'' 神经科学研究表明，人类在进行语言表述时，皮层下通路（Subcortical Pathways）会持续将底层情绪状态外显为面部微表情，使情感的流动与言语的表达形成紧密的同频共振~\cite{ledoux1996emotional}。面部机器人的控制工程应当借鉴这一机制启发，以达到更自然的人机交互效果：即情绪信号应当直接从模型实时的内部认知流中提取，并流式驱动表情更新。然而，当前主流方案——无论是早期的显式规则切换，还是近期基于 LLM 的结构化输出与非言语行为调度——普遍令模型在生成对话内容的同时附带离散情绪标签，再据此映射预设表情；标签虽可与回复一并产生，其语义单元仍停在话轮（Turn）尺度。相比之下，语言生成是以 Token 为基本单元自回归流式推进的，其内部往往交织着高频的句内（Intra-utterance）情感转折。这种时序粒度错配不可避免地导致了面部执行相对于语言内容轨迹的错位，并在整句尺度上抹平了本应精细可辨的动态情感轨迹。

为了解决上述瓶颈，本文提出了 EmoManifold：一种在流式解码过程中直接从大模型隐状态（Hidden States）中读回连续情感坐标，并实时外显为面部微表情的全新架构。在表征机制上，该方案摒弃了依赖外部离散标签的传统做法，建立了一条“隐状态 $\rightarrow$ 连续 VAD 轨迹 $\rightarrow$ 物理面部”的直通管线：在每个 Token 发射的瞬间，瞬时隐状态被直接投影至 VAD 情感子空间，该连续信号随即被平滑映射，用以驱动 29 自由度的面部硬件系统。该架构无需繁重的参数微调或外部情感 API，仅依赖原生前向传播即可高效运行。通过这种极简管线，物理执行与认知 Token 发射共享同一时钟，真正实现了“情动于内、形于外”的效果。

本文的主要贡献如下：
\begin{itemize}
\item 提出一条免训练的隐状态$\rightarrow$VAD$\rightarrow$面部直通管线：情感轴由解嵌入矩阵一次性构造，无需语料前向传播或参数微调，逐 token 投影在本地工控机上仅需约 $0.7$~ms 的附加开销；
\item 以语境三元组讽刺压力测试系统验证该读回真正整合了上下文语义、而非表面词汇匹配，且这一结论在 Qwen2.5-0.5B 与 Llama-3.2-3B 两个不同规模的 backbone 上一致成立；
\item 在 29 自由度实体机器人上完成四条件同场闭环评测与人因验证，证明逐 token 情感执行在物理保真度与主观偏好上均显著优于现有话轮级方案。
\end{itemize}
论文后续结构安排如下：第二节回顾相关研究工作；第三节详细阐述本文提出的核心方法；第四节汇报实验设计与系统评估结果；第五节讨论局限；第六节给出结论。

\section{RELATED WORK}
\label{sec:related}

机器人面部表情生成的研究可追溯至基于面部运动编码系统（FACS）的动作单元描述传统~\cite{ekman1978facs}，以及早期交互系统（如 Kismet）在二维情感空间中实现连续动态表情过渡的开创性实践~\cite{breazeal2002designing}。近年来，高度仿真的面部硬件平台（如 Emo~\cite{hu2024emo}）以及面向 Ameca 机器人的 X2C 数据集~\cite{li2025x2c}极大提升了机械面部的连续形变能力。然而与之形成反差的是，在控制层面，实现与流式言语高频同步的自动化自适应表情管线仍是人机交互领域的突出瓶颈。随着大语言模型的普及，业界已迅速转向由 LLM 驱动的新范式（如 FurChat~\cite{cherakara2023furchat}、SAFE~\cite{lee2023safe}、Nadine~\cite{kang2024nadine} 及 Expressive Furhat~\cite{abbo2025expressive} 等）。其中，当前主流路线通常仍以外部离散标签驱动面部：例如 Mishra 等~\cite{mishra2023realtime}为即将发出的话轮预测离散情绪，Xpress~\cite{antony2025xpress}则由模型输出情绪类别与强度。二者构成了本文实验的主要对照系统。

然而，语言生成是以 Token 为基本单元自回归推进的。话轮级离散情绪标签——即便与回复一并产生或事后附加，其语义单元仍是整段话轮——在结构上无法刻画句内连续情感漂移（例如否定、转折或讽刺情形）。相比单一类别标签，效价-唤醒度-支配度（VAD）连续情感空间~\cite{russell1977evidence,mohammad2018nrcvad}更适于细粒度表情驱动：它保留强度梯度与句内轨迹，并与面部机器人长期使用的连续 Affect Space 控制~\cite{breazeal2002designing}以及基于环状模型的表情映射（第~\ref{sec:actuator}节）相一致。同时，机制可解释性研究表明，LLM 隐空间中天然存在可线性读出的低维情感结构，但其情感方向的识别方式仍依赖对标注或对比语料做前向传播（如对比激活分析，或对隐状态做 SVD 分解），且往往需额外训练干预模块才能实现可控操作~\cite{tigges2024sentiment,reichman2026emotions}。本文表明，与 VAD 对齐的情感子空间亦可直接从静态解嵌入矩阵免训练构造，构轴过程无需扫描文本语料。基于这一观察，本文摒弃将表情编码为离散符号字段的传统做法，改为在解码过程中直接从隐状态读回连续 VAD 轨迹，并以 Token 时钟驱动面部执行。

\section{METHOD}
\label{sec:method}

图~\ref{fig:1}概述了 EmoManifold 的整体架构。我们将``从语言内部表征到物理表情''这一端到端映射解耦为三个可独立标定的阶段：（A）情感轴挖掘与子空间标定；（B）逐 token 流式投影；（C）表情映射与物理执行。其中阶段 A 为一次性离线过程，阶段 B 与 C 在运行期以内置的前向传播开销实时完成。需要说明的是，系统名``EmoManifold''中``流形''一词取其广义比喻含义，指代 LLM 隐空间中结构化、可线性读出的低维情感表征，本文的具体实现是由三条情感轴张成的\emph{线性}子空间投影。具体细节如下所述：

\subsection{情感轴挖掘与子空间标定}
\label{sec:axis_mining}

本阶段的目标是在不引入任何训练的前提下，于 LLM 隐空间中显式构造出与心理学 VAD 模型~\cite{russell1977evidence}对齐的三条情感轴，并由其张成三维 VAD 情感子空间。
设 $\mathbf{W}_{\mathrm{out}} \in \mathbb{R}^{|\mathcal{V}| \times d}$ 为模型的解嵌入（unembedding）矩阵，其中 $|\mathcal{V}|$ 为词表大小、$d$ 为隐层维度。
我们从 NRC-VAD 词典~\cite{mohammad2018nrcvad}中为每一维构造正负极词簇（pole word clusters）$\mathcal{C}^{+}_k$ 与 $\mathcal{C}^{-}_k$，$k \in \{V, A, D\}$：先按该维标注的极端程度排序，再只保留在目标模型分词器下恰好编码为单个 token 的词，并取每极各 $N$ 个。
对给定极性（$* \in \{+, -\}$）的词簇 $\mathcal{C}^{*}_k$，计算其在解嵌入矩阵中对应行向量的平均嵌入：
\begin{equation}
    \bar{\mathbf{e}}_{\mathcal{C}^{*}_k} = \frac{1}{|\mathcal{C}^{*}_k|}\sum_{w \in \mathcal{C}^{*}_k} \mathbf{W}_{\mathrm{out}}[\mathrm{id}(w), :],
\end{equation}
其中 $\mathrm{id}(w)$ 为词 $w$ 对应的（唯一）token 索引。
第 $k$ 维情感轴定义为两极词簇质心的归一化差向量：
\begin{equation}
    \mathbf{v}_k = \frac{\bar{\mathbf{e}}_{\mathcal{C}^{+}_k} - \bar{\mathbf{e}}_{\mathcal{C}^{-}_k}}{\bigl\|\bar{\mathbf{e}}_{\mathcal{C}^{+}_k} - \bar{\mathbf{e}}_{\mathcal{C}^{-}_k}\bigr\|_2}.
    \label{eq:valence_axis}
\end{equation}
三条情感轴 $\{\mathbf{v}_V, \mathbf{v}_A, \mathbf{v}_D\}$ 共同张成 VAD 情感子空间；后文在讨论逐维投影与构轴过程时称``情感轴''，在讨论轨迹几何、正交性与表情映射时称``情感子空间''。
极词数 $N$（默认取 $50$，敏感性分析见第~\ref{sec:exp_subspace}节）为构轴的关键超参数。
由于原始投影值的数值范围依模型与维度而异，我们另以少量含词典词的句子做一次性离线最小二乘拟合，得到逐维仿射参数 $(s_k, b_k)$，将投影值对齐至词典语义尺度 $[-1, 1]$（AdaptiveScaler）；推理时该参数固定。

\subsection{逐 Token 流式投影}
\label{sec:projection}

运行期，模型以因果解码逐 token 生成回复。
在第 $t$ 步，设 $\mathbf{h}_t \in \mathbb{R}^{d}$ 为末层最后位置的隐状态，即刚发射 token 的上下文表示。
我们对其做 L2 归一化以消除隐状态范数随位置的漂移，再沿三条情感轴投影至 VAD 情感子空间并施加标定：
\begin{equation}
\begin{gathered}
    \hat{\mathbf{h}}_t = \frac{\mathbf{h}_t}{\|\mathbf{h}_t\|_2}, \\[2pt]
    \tilde{z}_{t,k} = \mathrm{clip}\bigl(s_k\,\mathbf{v}_k^\top\hat{\mathbf{h}}_t + b_k,\,-1,\,1\bigr),
    \quad k \in \{V, A, D\}.
\end{gathered}
\label{eq:projection}
\end{equation}
由此得到与 token 发射严格同步的连续情感轨迹 $\{\tilde{\mathbf{z}}_t\}$。
区别于将离散情感标签作为结构化输出字段、以话轮为语义单元的调度方案~\cite{mishra2023realtime}，该读回在每个解码步即时可用，天然具备句内时间分辨率——这正是跟随句内情感变化、而非依赖单一话轮级标签的结构性前提。
由于隐状态在标准前向传播中本已计算，投影仅引入三次 $d$ 维点积。

\subsection{表情映射与执行}
\label{sec:actuator}

本阶段将式~\eqref{eq:projection}给出的连续 VAD 坐标转化为面部执行器指令，分两步完成：先以基本表情空间为中介，将坐标连续映射为若干基本表情的融合权重（表情映射）；再将该权重进一步融合为具体的舵机指令，并施加面向硬件的平滑与限速（硬件执行）。

\textbf{VAD 到基本表情的连续映射。}
直接在 VAD 情感子空间中逐自由度标定机器人面部代价高昂且不可迁移；相比之下，基本表情空间为面部硬件提供了自然的标定基。
为此我们采用模糊 Kohonen 聚类网络（FKCN）~\cite{han2010fkcn}，将子空间坐标的效价--唤醒（VA）分量连续映射为七种基本表情（中性、快乐、惊讶、恐惧、悲伤、厌恶、愤怒）的融合权重 $\boldsymbol{\omega}_t \in \Delta^{6}$（非负且和为一）。
表情映射取 VA 平面，是因为面部表情与效价--唤醒的对应关系在心理学与表情合成文献中最为成熟~\cite{russell1980circumplex,breazeal2002designing}；支配度作为子空间的第三维参与上游表征与评测（第~\ref{sec:experiments}节），并为需要区分支配性的后续表情载体保留扩展接口。

FKCN 由 $P = 13$ 个模糊原型 $\{(\mathbf{c}_j, \mathbf{w}_j)\}_{j=1}^{P}$ 构成，其中 $\mathbf{c}_j \in \mathbb{R}^2$ 为原型在 VA 平面中的坐标，$\mathbf{w}_j$ 为该原型所属基本表情的 one-hot 向量；原型坐标按环状情感模型（circumplex model）~\cite{russell1980circumplex}给出的效价--唤醒区位锚定，使七种基本情绪各据典型区域。
给定输入 $\mathbf{p}_t = (\tilde{z}_{t,V}, \tilde{z}_{t,A})$，计算其到各原型的平方距离 $d_{tj} = \|\mathbf{p}_t - \mathbf{c}_j\|^2$，并由反距离归一化得到模糊隶属度
$\mu_{tj} = \bigl(d_{tj}\sum_{l=1}^{P} d_{tl}^{-1}\bigr)^{-1}$（与原型重合时退化为硬指派）。
输出权重为隶属度对原型标签的加权和：
\begin{equation}
    \boldsymbol{\omega}_t = \sum_{j=1}^{P} \mu_{tj}\, \mathbf{w}_j .
    \label{eq:fkcn}
\end{equation}
与最近邻式的硬分类不同，该映射在整个 VA 平面上连续：位于原型之间的坐标会产生多种基本表情的软混合，而不是突然跳到单一类别。

\textbf{硬件执行与信号调优。}
执行层将七维权重融合为舵机指令。
每种基本表情对应一个离线标定的预置向量（preset）$\mathbf{p}^{(m)} \in [0,1]^{29}$：标定时逐关节调节物理面部至该表情的目标位形，并按各通道行程上下限将关节角归一化为无量纲因子（factor）。
运行期，29 维目标因子由 FKCN 权重对预置向量线性融合得到：
\begin{equation}
    \mathbf{f}_t = \sum_{m=1}^{7} \omega_{t,m}\, \mathbf{p}^{(m)}, \qquad \mathbf{f}_t \leftarrow \mathrm{clip}(\mathbf{f}_t,\, 0,\, 1),
    \label{eq:fusion}
\end{equation}
再经逐通道行程映射转换为舵机角度，通过串口下发。运行期对融合后的表情目标施加轻量时域平滑与帧率限速，以抑制逐 token 更新带来的抖动并匹配舵机响应；默认超参与消融见第~\ref{sec:exp_hardware}节。

上述融合在预置表情权重空间中进行，因此与具体舵机如何排布无关：若更换面部显示方式，只需为新载体重新标定七种基本表情的预置向量，从隐状态到 VAD、再到 FKCN 的计算保持不变。

\section{EXPERIMENTS}
\label{sec:experiments}

实验部分旨在回答三个层层递进的问题：（A）我们提取的 VAD 情感子空间是否可靠？（B）读出的情感信号是否真正融合了上下文语境，而非对表面词汇的机械映射？（C）该情感信号经映射与执行后，能否在实机面部上保真呈现？除特别说明外，实验模型默认为Qwen2.5-0.5B，情感轴与标定参数按第~\ref{sec:axis_mining}节所述、以每极 50 个英文极词离线构建。

\subsection{情感子空间可靠性}
\label{sec:exp_subspace}

\begin{figure}[t]
    \centering
    \includegraphics[width=\columnwidth]{fig/fig2.pdf}
    \caption{极词数 $N$ 扫描下的词级 Spearman 相关系数。实线为六模型均值，阴影带为 min--max 范围。三维度均在 $N \approx 50$ 后饱和。}
    \label{fig:2}
\end{figure}

我们从 NRC-VAD 词典中另取 300 个未参与构轴的 hold-out 评测词（每个维度 100 词，按其在 NRC 标注中最突出的维度归组）：若第 $k$ 维情感轴可靠，这些词在该轴上的投影排序应与词典对该维度的人工标注一致。具体地，将每个词在解嵌入矩阵中的行向量归一化后与对应轴做点积，再经 AdaptiveScaler 标定，得到模型给出的 VAD 值，并与 NRC 词典人工标注的 VAD 值计算 Spearman 秩相关 $\rho$。为了让不同模型在完全相同的词表上评测、结果可直接比较，评测词均筛选为在全部五个对照模型（2B--8B 的五个开源 LLM）的分词器中都恰好编码为单个 token 的词——多 token 词在解嵌入矩阵中没有唯一的行向量，无法跨模型公平对比。

轴的质量与每极极词数 $N$ 相关。图~\ref{fig:2}展示了 $N$ 从 10 到 80 变化时，六个模型在同一评测词表上的 $\rho$。三个维度呈现一致的规律：$N$ 较小时轴不稳定，随 $N$ 增大相关系数上升，并在 $N \approx 50$ 后趋于饱和，据此取 $N{=}50$ 作为后续实验的默认值。考虑到部署模型 Qwen2.5 的预训练语料以英文和中文为主~\cite{qwen2024qwen25}，我们又改用中文极词重复整个流程（其余对照模型的分词器以英文语料为主，非英文语言难以凑齐足够多的单 token 极词，不便做同等条件下的对照），得到 $\rho_V = 0.823$、$\rho_A = 0.803$、$\rho_D = 0.702$，表明同一套构轴流程在中文上同样可靠。

第~\ref{sec:exp_subspace}节验证了每一维单独的可靠性，但下游无论是逐维读数的直接使用，还是按距离计算的表情映射（第~\ref{sec:actuator}节），都还依赖另一个性质：三条情感轴方向应近似互不重叠，且这套跨维几何结构不应是某一模型、某一语言下的偶然产物。为此，我们在部署模型 Qwen2.5-0.5B 与表~\ref{tab:e2_cross_model_spearman}中已出现的 Llama-3.2-3B 上，各自以英文极词（$N{=}50$）独立构轴并检验轴间正交性；同时预置五组跨语言情绪词簇（恐惧、舒适、支配、力量、平静），每簇含英语、中文及另外三种语言的同义对应词——其余语言覆盖西班牙语、波兰语、葡萄牙语、阿拉伯语、意大利语、荷兰语、德语、法语与日语，且词在\emph{对应}模型分词器下均为单 token——将各词投影至挖掘所得 VAD 子空间后计算簇内平均两两余弦，并以随机三维正交基上的同指标（每簇 100 次）作为阴性对照。图~\ref{fig:3}a给出这一几何结构的概念示意，图~\ref{fig:3}b汇总英文极词构轴的定量结果：Qwen 上 $|\cos|\le0.194$，凝聚度 $0.913$（随机 $0.410$）；Llama 上 $|\cos|\le0.158$，凝聚度 $0.963$（随机 $0.365$）。本节关心的是这套几何结构本身是否具有普适性，而非单一部署场景，因此即便 Llama 这类以英文语料为主的模型在中文分词上更容易把词切碎、可用的单 token 极词更少，我们仍将 Qwen 与 Llama 都换成中文极词重复上述流程：结果处于同一量级，Qwen 上 $|\cos|\le0.220$，凝聚度 $0.898$；Llama 上 $|\cos|\le0.282$，凝聚度 $0.965$，表明该跨语言情感几何在两个模型、两种语言的组合下均成立，并非单一模型、单一语言下的偶然现象。

\subsection{语境敏感性}
\label{sec:exp_sarcasm}

\begin{figure}[t]
    \centering
    \includegraphics[width=\columnwidth]{fig/fig4.pdf}
    \caption{语境三元组讽刺压力测试（$n{=}200$，Qwen2.5-0.5B；三元组构造见正文）。
    \textbf{(a)}~句级投影效价 $V$：S（讽刺）、P（真诚正面）与 N（字面负面）。雨云图由半小提琴（核密度）、箱线（IQR）与逐三元组散点组成；菱形为 bootstrap 均值 $\pm$95\% CI，灰线连接匹配三元组。
    \textbf{(b)}~S 与 P 中首要锚定正面关键词处的 token 级效价（$n{=}194$）。}
    \label{fig:4}
  \end{figure}

上一节的词级相关系数只能说明投影与词典先验一致，尚不能说明读回是否整合了语境：若其本质等价于查词典，则同一正面措辞无论出现在何种上下文中都会得到相近的高效价，表情便无法跟随句内语用转折。讽刺恰好是检验这一点的对抗场景——讽刺句用正面措辞传递负面意图，表面词汇与真实情感方向相反~\cite{abufarha2022isarcasm}。

我们以公开的讽刺检测基准 iSarcasmEval~\cite{abufarha2022isarcasm} SubTask C 英文测试集为底本，该集提供 200 对``讽刺句 + 表达相同意图的非讽刺改写''。直接使用原句有两个问题：许多句子依赖特定文化背景（球队、政客、品牌等），且孤立的引语本身不含判断讽刺所需的情境。为此，我们按固定协议将每对人工改写为一组语境三元组，每条由``一句可观察的情境 + 一句引语''构成，情境改用通用日常场景替代原有的文化专名：S（讽刺）在不利情境下给出正面引语，P（真诚正面）在有利情境下给出\emph{逐词相同}的正面引语，N（字面负面）在不利情境下给出负面引语。例如，S 与 P 的引语均为\emph{``Your team played so well today!''}，仅前置情境为输/赢之别；N 则将引语改为字面负面表述。由于 S 与 P 的引语逐词相同，两者间的任何投影差异都只能来自语境，而非措辞本身。我们同时为每条三元组标注 1--3 个锚定情绪关键词（如上例中的 well），供后续 token 级分析使用。

我们对每组三元组做与全文相同的前向投影：句级效价取句末 token，关键词级效价取锚定词所在 token。图~\ref{fig:4}a 显示，200 组三元组中 S 与 N 的句级效价大范围重合（81.5\% 相差不足 0.15），而引语相同的 S 显著低于 P（$\Delta V=-0.19$；Wilcoxon，$n{=}200$，$p<10^{-11}$）。三组配对差异均显著。

句级差异仍可能来自句中其他词。为排除这一点，我们把对比收窄到单个 token：同一个正面关键词（如 well）在 S 与 P 中位置与词形相同，仅前置情境不同。图~\ref{fig:4}b 报告首要锚定关键词处的 token 级效价：讽刺语境下平均低 $0.22$（全部共现关键词上为 $-0.20$），而唤醒度与支配度的偏移均小于 0.07——变化几乎只发生在效价维度，与讽刺``改变的是褒贬方向、而非激动程度''的心理学刻画一致~\cite{leggitt2000emotional}。该关键词在 S、P 两种语境下词形与句内位置完全相同，因此这一效价差异只能来自语境本身，说明读回反映的是整合上下文后的情感，而非查词典式的表面匹配。为排除该效应只是 0.5B 部署模型偶然行为的可能，我们在参数量更大的 Llama-3.2-3B 上，用同一批三元组与同一套构轴协议重复该分析：句级 $\Delta V(S{-}P){=}-0.20$，首要关键词处为 $-0.16$，方向与幅度均与 Qwen 一致，说明语境敏感性可推广至更大的模型。

\textbf{首先是执行保真度评测。} 机器人现场根据20条刺激句生成表情与回复，固定机位相机拍摄其面部，再由独立的开源表情分析器（Py-Feat~\cite{cheong2023pyfeat}）逐帧从视频里读出效价与唤醒，检验这些读数的变化方向能不能对上指令的变化方向，评测在同一面部机器人、同一机位的一场录制中完成。四个条件对\emph{同一段回复}给出各自的表情控制。（1）\textbf{EmoManifold}：每个生成 token 更新一次 VAD 并驱动面部。（2）\textbf{Mishra 式话轮级基线}~\cite{mishra2023realtime}：按其原文的分类提示词，对整句回复输出六类离散情绪之一，整句期间保持该表情。（3）\textbf{Xpress 式话轮级基线}~\cite{antony2025xpress}：按其官方提示词输出更细的情绪标签与高/低强度，同样在整句期间保持。（4）\textbf{乱序对照}：将 EmoManifold 的逐 token 指令在时间上打乱后执行——动态幅度不变，但时序被破坏。两条基线使用 GPT-4o-mini 对整句回复打标签——这与 Mishra、Xpress 原论文一致。

相机读回采用开源、与本文管线完全独立的表情分析工具 Py-Feat~\cite{cheong2023pyfeat}，对固定机位录像逐帧估计效价与唤醒。和目前公开可用的同类工具一样，Py-Feat 只输出效价、唤醒两维，没有可靠的支配度估计；这一限制恰好与执行映射所用的 VA 平面（第~\ref{sec:actuator}节）相容，因此实机评测仅在这两维上进行。

该检测器面向人类面部训练，直接用于机器人脸时读数存在固定的尺度压缩与维间串扰。为此，我们先用 40 段话轮级静止片段（Mishra/Xpress 条件下、显示表情固定且其效价、唤醒值已知的片段）做一次线性校准：对每一维分别拟合一条直线，把 Py-Feat 的原始读数映射到已知的显示数值上，拟合参数在四条件的全部动态试次上保持不变，校准集与句内转折评测完全分离。

主指标为事件级方向一致率：在每个 2 秒的滑动窗口内，只要指令的效价变化超过 0.3，或唤醒变化超过 0.2，就记为一次``事件''；如果校准后的相机读回在同一窗口内的变化方向与指令一致，就记为一次``命中''，随机水平为 50\%。由于相邻窗口高度重叠，我们先在每条试次内取命中率均值，再对 20 条试次做 bootstrap 得到置信区间。另外，我们用 EmoManifold 相对``整句单一表情''话轮级基线额外解释的面部方差比例，衡量逐 token 动态相对静态基线的增益。四条件共用固定 0.5 秒的执行--检测滞后。

图~\ref{fig:5} 显示，仅 EmoManifold 能在句内同步跟随指令转折：效价方向一致率 87.5\%（95\% CI $[76.7,96.0]$，$p<10^{-4}$），唤醒 69.6\%（CI $[56.8,81.7]$，$p{=}0.001$）；Mishra、Xpress 与乱序对照均接近 50\% 机会水平（效价 37.2\%--46.5\%，唤醒 53.8\%--58.8\%）。循环移位负对照（Fisher 合并 $p<10^{-23}$）排除偶然对齐；乱序条件与 EmoManifold 动态幅度相同但时序被打乱，其一致率与 $R^2$ 增益（$\le+0.05$）仍与基线无异，而 EmoManifold 额外解释 21.8\%/18.9\% 面部方差（效价/唤醒，图~\ref{fig:5}c）。这表明句内物理跟随的关键是指令时序，而非更大的动态幅度。

\textbf{超参数鲁棒性的消融验证。}上述结论建立在默认的 EMA 系数 $\alpha{=}0.6$、原型数 $P{=}13$ 之上。由于二者只作用于指令侧的确定性计算，而舵机、相机与检测器对所有取值共模，我们在同一场 20 条指令轨迹上离线重放完整显示通路（FKCN $\to$ EMA $\to$ 10\,fps 缓入缓出插值 $\to$ 单帧变化上限），沿用相同的事件阈值与窗口，以避免逐一重录实机视频。默认设定下重放给出效价 84.4\%、唤醒 67.7\%，与相机实测的 87.5\%/69.6\% 相当；而同一管线作用于时序打乱的指令时仅 44\%--48\%（唤醒 40\%--45\%），说明重放结果可信、该指标并非恒过。在此基础上扫描 $\alpha\in\{0.3,0.6,0.9\}$、默认 $P{=}13$ 与两种 $P{=}7$ 构造（各保留每类原型中的不同一个），共九种设定：效价一致率 75\%--87\%、唤醒 68\%--74\%，均远高于上述地板，即句内转折的可执行性不由超参决定。

\textbf{跨显示载体的可迁移性验证。}图~\ref{fig:7} 给出同一段对话下 Grimace 仿真脸与实体面部在对应抽样时刻的表情对照：两者变化一致，验证了第~\ref{sec:actuator}节所述融合权重与显示载体无关的设计。

\textbf{面向人类观察者的识别与偏好验证。}相机回读只能说明物理层面是否跟随指令，无法说明人类观察者能否识别这些表情、是否更偏好逐 token 的动态变化。为此我们另设两项无声视频问卷（$n{=}20$）；被试在实验前均知情同意，问卷匿名且不采集可识别个人信息。

\textbf{任务一（认表情）}回答``表情是否可被正确识别''：模型按目标情绪生成回复，被试观看 EmoManifold 驱动的面部视频并判断其情绪类别，正确率与同机位人工标定的\emph{预设标准表情}（代表该硬件可辨识度的上限）比较。结果显示，EmoManifold 正确率 85.5\%，预设标准表情 90.5\%（Wilcoxon $p{=}0.013$），差距不大；进一步分析发现，两者的误判都集中在恐惧--惊讶、悲伤--厌恶等本身相近的情绪对上，说明这部分损失来自机器人面部呈现能力的上限，而非 EmoManifold 把情绪映射错了。

\textbf{任务二（句内匹配）}回答``逐 token 的动态表情是否更受偏好''：对含句内情感转折的句子，被试在三段视频——EmoManifold 的逐 token 动态表情、整句保持单一表情、以及打乱指令顺序——中选出``更贴合情感变化''的一段。结果 EmoManifold 被选中 83.5\%，乱序对照 11.5\%，整句静脸仅 5.0\%（20 名被试全部偏好 EmoManifold，单侧 Wilcoxon $p{<}10^{-6}$），表明句内动态表情不仅能被识别，也确实更受人类观察者青睐。

\section{DISCUSSION}
\label{sec:discussion}

上述实验构成一条连贯的证据链：挖掘得到的 VAD 子空间在跨模型、跨语言条件下可线性读出；同一读回随语用语境而非表面措辞变化；经 FKCN 与预置表情映射后，指令可在实体面部上被保真回读，并在主观上优于话轮级或时序打乱对照。相对话轮级离散句标签，主要工程收益在时间粒度：表情可跟随句内效价与唤醒变化，而无需等待整句类别。

尽管如此，本研究仍存在以下局限性。
在多模态整合层面，当前评测确立了 Token 速率下的表情--内容对齐，但尚未把该通道与可听播报耦合：人因实验仅以无声视频评估表情本身，我们不声称表情--语音同步；系统也尚未生成与语音同步的唇形——口部自由度需同时承担发音与表情两项功能，二者简单叠加容易相互干扰。一个自然的后续方向——我们也正在探索——是将同一隐状态读回应用于开源语音原生模型，沿音频 token 流投影情感，使面部更新与播报时钟共享；唇形则可作为该共享时间轴上的互补控制器。
在交互设计层面，机器人面部受限于物理自由度与预置表情基，对邻近情绪的可分辨性存在上限；更值得关注的是，直接外显内部情感状态未必适合所有交互场景——人类社会互动中常需要抑制、缓和或延后情绪表达，而当前管线只要读到信号就会如实显示，缺乏这样的调节空间。我们因此计划在投影与执行之间引入可配置、可关闭的轻量调节层（增益限制、时间保持与显式关闭开关），以便部署时选择何时显示、缓和或抑制内部信号。
在评测规模上，实机与人因实验的语料规模、被试人数与实验平台均较为有限。被试均知情同意（第~\ref{sec:exp_hardware}节）；更大样本复验留待后续。实机执行保真度与人因验证（第~\ref{sec:exp_hardware}节）也只部署了 Qwen2.5-0.5B 这一个模型：前面的情感子空间可靠性实验与语境敏感性实验已表明，同一套构轴与投影协议在 Llama-3.2-3B 上能得到相近的轴几何与语境敏感性，因此我们把实机录制与人因评测的资源集中在这一部署侧模型上；在另一模型上重复整套硬件与人因评测，将是进一步巩固这一结论的后续工作。

\section{CONCLUSION}
\label{sec:conclusion}

本文表明，面部机器人无需依赖整句离散情绪标签，即可直接从大语言模型（LLM）流式解码的隐状态中读回连续 VAD 情感坐标，并以 Token 级的时间粒度驱动物理表情。跨实验来看，该免训练管线给出语境敏感的 VAD 读回，在实体面部上对指令的句内效价--唤醒转折跟随优于话轮级基线，并降低端到端表情响应延迟，为实现快速、细腻且可验证的具身情感交互提供了一条可行路径。
