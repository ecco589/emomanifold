EmoManifold — RA-L multimedia attachment (data)
====================================================

Purpose
-------
This zip contains reproducibility DATA referenced by the paper
(contextual sarcasm triplets for Experiment B). It is a data
repository attachment, NOT an appendix and NOT supplemental text
or extra figures.

Minimum requirements
--------------------
- Any text editor or JSON viewer
- Optional: Python 3.8+ with the standard library (json) to load
  b1_sarcasm_triplets/context_triplets_en.json

How to open
-----------
1. Unzip this archive.
2. Read Summary.txt for a file-by-file list.
3. Load context_triplets_en.json (UTF-8). Field "items" has 200
   triplets; "n" should equal 200.
4. rewrite_protocol.md documents how the triplets were written
   from iSarcasmEval SubTask C (human rewrite rules only).
